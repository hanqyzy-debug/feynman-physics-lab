# Лаборатория Фейнмана

Интерактивное дополнение к главам 1–6 первого русского выпуска «Фейнмановских лекций по физике». 26 опытов (20 с объёмным WebGL-режимом), 31 краткое объяснение параграфов и 30 вопросов с обратной связью. Глава 7 «Теория тяготения» и следующие главы не включены.

[Открыть лабораторию](https://hanqyzy-debug.github.io/feynman-physics-lab/) · [Границы глав и источники](docs/chapter-boundaries.md)

Проект работает без сборки, CDN, шрифтов из сети и сторонних библиотек. Исходный DOCX и полный текст книги в репозиторий не добавлены. Все прежние модели сохранены: `3d-atoms-molecules.html`, `life-universe.html`, `experiments.html` (бывшая главная).

## Модели по главам

- Глава 1: газ, испарение, соль и реакция — 3D.
- Глава 2: заряды, электромагнитная волна, фотоны и двухщелевой опыт — 3D.
- Глава 3: клетка, ДНК/РНК/белок, цикл Кребса, дыхательная цепь и фермент — 3D; спектры и время реакции — графические опыты.
- Глава 4: спуск с учётом энергии, подъёмная машина и пружина — 3D.
- Глава 5: эхо/триангуляция и радиоактивные часы — 3D; часы и шкала размеров — графические опыты.
- Глава 6: монеты и случайное блуждание — 3D; плотность и неопределённость — графики.

[Каталог и источники сверки на 03.11.2026](docs/model-catalog.md). Биология доступна прямо в главе 3 и через быстрые ссылки главной страницы.

## Локальный запуск

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/`. Прямые ссылки на главы: `#chapter-1` … `#chapter-6`. Старые `#chapter1` … `#chapter3` перенаправляются к новым главам.

## Проверки

```sh
node --test tests/run.cjs
python3 tools/audit_source.py '/путь/к/исходному.docx'
```

Тесты проверяют физические соотношения, ансамбль случайных шагов, атомный и энергетический балансы, границу курса, запуск всех 26 рендереров на крайних параметрах и 16 сохранённых canvas-моделей. Браузерная проверка описана в [QA.md](docs/QA.md).

Ответы сохраняются только в localStorage этого браузера, без отправки данных. Если сохранение недоступно, курс продолжает работать. Анимации останавливаются общей кнопкой, по умолчанию при системном ограничении движения, в скрытой вкладке и вне видимой области. Изменения ползунков доступны и при паузе.

## GitHub Pages

Статические файлы лежат в корне. Подходит публикация корня ветки `main` в GitHub Pages без отдельной сборки. Внешние зависимости отсутствуют. CSS и JavaScript имеют параметр версии, чтобы после обновления не смешивались старые и новые файлы.

## Работа с 3D

Камера вращается мышью и стрелками клавиатуры. Для жестов нужно включить «Вращать»: тогда доступны вращение пальцем и масштаб двумя пальцами. В обычном режиме область модели позволяет прокручивать страницу. Есть ползунок масштаба, возврат камеры и переключение к прежней схеме/графику. Расчёт и 3D используют одно состояние опыта.

3D использует встроенный WebGL 1 без внешних библиотек. При отсутствии WebGL или потере контекста остаётся рабочая 2D-схема. При смене главы ресурсы освобождаются. Интерактивная проверка реальной отрисовки и восстановления: `tests/graphics.html` на локальном сервере.
